# UCS Data Explorer (RK7 PRO 4.0)

Run `python main_webview.py` or `Start RK7 Pro (Webview).bat`, then select **UCS Tools**. Choose a `.udb` file, enter your UCS dealer credentials, and select **Upload & analyze**. RK7 PRO sends the file directly to the upload form discovered on `https://utils.ucs.ru/udbtools/`. The UCS website is not embedded in this workflow.

The tool retrieves the current upload form and its CSRF field, submits the file over HTTPS with HTTP Basic Authentication, then follows UCS's `udb2abs` conversion form and `showdbinfo` form. It shows the DB-info summary immediately after those steps. It then fetches table pages in the background, with up to four concurrent authenticated read requests and a limit of 50,000 rows per table. The workspace has a fixed table browser, row search across all fields or one field, sortable columns, configurable visible columns, pagination, and a record inspector showing every field without horizontal scrolling. Clicking a table opens its imported rows or fetches that table immediately. Export JSON is available after background loading finishes; CSV exports the current table view. Credentials remain in memory for the active UCS session and are not written to application files or logs.

The upload, conversion, DB-info, and `showdbtable` links were verified against HTML supplied by the user. One DB-info page declared 51 tables but rendered 52; the app retains every listed table and shows the discrepancy. The PRINTCHECKS detail HTML confirmed UCS uses an HTML table with `<td>` headers and may omit trailing empty cells; the parser handles both. Live authenticated responses could not be verified in this development environment. The client discovers form fields and table links at runtime and fails with a clear error when the site's layout differs. It only invokes the conversion and read actions described above; it does not invoke repair or deletion actions.
